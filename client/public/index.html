🔍 Fake Investment Detection System

A comprehensive application for detecting and preventing fraudulent investment schemes.

Key Features

🛡️ Advanced Detection

AI-powered fraud detection algorithm analyzes investment opportunities in real-time.

📊 Detailed Analysis

Comprehensive reports with fraud scores and risk assessments for each investment.

⚡ Real-Time Insights

Instant feedback and recommendations to make informed investment decisions.

Getting Started

  1. Install dependencies: npm install
  2. Configure environment variables (.env files)
  3. Start the application: npm run dev
  4. Navigate to http://localhost:5173

Technology Stack

Frontend

  • React 18 + TypeScript
  • Vite (build tool)
  • Tailwind CSS (styling)
  • Zustand (state management)
  • Axios (HTTP client)

Backend

  • Express.js + TypeScript
  • MongoDB (database)
  • JWT (authentication)
  • Joi (validation)
