# Contributing to Fake Investment Detection

We appreciate your interest in contributing! This document provides guidelines for contributing to the project.

## Getting Started

1. Fork the repository
2. Clone your fork
3. Create a new branch for your feature (`git checkout -b feature/AmazingFeature`)
4. Make your changes
5. Commit your changes (`git commit -m 'Add AmazingFeature'`)
6. Push to your branch (`git push origin feature/AmazingFeature`)
7. Open a Pull Request

## Development Guidelines

### Code Style
- Use TypeScript for type safety
- Follow ESLint rules defined in project
- Use meaningful variable and function names
- Add comments for complex logic

### Commit Messages
- Use present tense ("Add feature" not "Added feature")
- Use imperative mood ("Move cursor to..." not "Moves cursor to...")
- Limit first line to 72 characters

### Pull Requests
- Provide clear description of changes
- Reference any related issues
- Ensure tests pass
- Update documentation as needed

## Issue Reporting

When reporting issues:
1. Check if issue already exists
2. Provide clear title and description
3. Include steps to reproduce for bugs
4. Specify expected and actual behavior

## Code Review Process

1. At least one maintainer review required
2. All tests must pass
3. No conflicts with main branch
4. Code follows project guidelines

## Questions?

Feel free to open an issue or discussion for questions about contributing.

Thank you for helping improve this project!
